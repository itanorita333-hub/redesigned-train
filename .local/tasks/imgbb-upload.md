# Integrasi Upload ImgBB\n\n## What & Why\nHantar fail imej ke ImgBB sebelum memasukkannya ke kandungan Markdown supaya aplikasi menyimpan URL imej yang stabil, bukan data URL atau blob URL pelayar.\n\n## Done looks like\n- Pengguna boleh upload imej dari editor seperti biasa.\n- Server menghantar fail ke ImgBB menggunakan Secret `IMGBB_API_KEY` yang tidak pernah dihantar ke frontend.\n- Selepas upload berjaya, URL ImgBB dimasukkan sebagai satu baris Markdown dan muncul dalam senarai thumbnail.\n- URL image manual kekal boleh digunakan tanpa API key.\n- Jika Secret tiada atau ImgBB gagal, editor memaparkan mesej yang jelas dan tidak menyimpan URL rosak.\n- Replace image melalui fail juga menggunakan ImgBB.\n\n## Out of scope\n- Memaparkan atau menyimpan API key dalam UI atau dokumen.\n- Cloud storage selain ImgBB.\n- Memadam imej daripada akaun ImgBB apabila Markdown image dipadam.\n\n## Steps\n1. **Server upload proxy** -- Tambah endpoint multipart yang membaca `IMGBB_API_KEY` di server, memvalidasi jenis/saiz imej, menghantar fail ke ImgBB dan memulangkan URL yang diperlukan sahaja.\n2. **Editor upload flow** -- Tukar upload dan replace fail supaya melalui endpoint server, kekalkan URL manual sebagai laluan tanpa API key, dan tambah state loading/error yang jelas.\n3. **Persistence and compatibility** -- Pastikan hanya URL ImgBB masuk ke Markdown, senarai media dan save/reload; kekalkan sokongan video lama tanpa cuba menghantarnya ke ImgBB.\n4. **Verification** -- Uji konfigurasi Secret tiada, respons ImgBB gagal, upload berjaya, replace, save/reload dan jalankan build, tests serta semakan workflow.\n\n## Relevant files\n- `server.js:1-85`\n- `js/app.js:780-1120`\n- `css/style.css:1038-1245`\n- `package.json:1-24`\n
