# Pengurus Media Editor\n\n## What & Why\nTambah pengurus imej dalam Edit Content supaya pengguna boleh memasukkan imej melalui URL atau fail upload terus dari editor Markdown, melihat semua imej dalam senarai satu baris, dan mengemas kini metadata tanpa mengedit sintaks Markdown secara manual.\n\n## Done looks like\n- Editor mempunyai field URL imej dan butang untuk memasukkan URL sebagai Markdown image.\n- Butang upload media membenarkan pengguna memilih fail imej dan terus menambahnya ke kandungan serta senarai media.\n- Setiap imej dipaparkan pada satu baris dengan thumbnail kecil, field nama/caption, dan butang Edit.\n- Dialog Edit membenarkan pengguna menukar caption/nama imej, menggantikan imej melalui URL atau fail, dan memadam imej.\n- Pemadaman memerlukan dialog pengesahan.\n- Menambah banyak imej menghasilkan satu baris berasingan bagi setiap imej.\n- Perubahan media diselaraskan dengan textarea Markdown, preview editor dan paparan halaman; URL imej kekal tersimpan bersama kandungan.\n- Media/video Markdown lama terus boleh dipaparkan tanpa rosak.\n\n## Out of scope\n- Sistem library media global merentas semua halaman.\n- Cloud object storage atau login pengguna.\n- Penyuntingan crop, resize atau filter imej.\n\n## Steps\n1. **Model dan parsing media** -- Kenal pasti image syntax yang sudah ada dalam kandungan Markdown, jana senarai media editor dengan identifier yang stabil, dan pastikan URL, caption serta perubahan fail disimpan dalam kandungan halaman.\n2. **Kawalan insert URL dan upload** -- Tambah field URL, nama/caption pilihan dan butang insert di sebelah kawalan upload; validasi URL dan fail imej, masukkan satu image Markdown untuk setiap item, dan berikan status ralat yang jelas.\n3. **Senarai media satu baris** -- Paparkan thumbnail, field nama imej dan butang Edit untuk setiap imej dalam editor; pastikan senarai dikemas kini apabila textarea berubah atau item ditambah.\n4. **Dialog edit media** -- Bina dialog untuk mengubah caption, menggantikan sumber melalui URL atau fail, dan memadam item dengan pengesahan sebelum mengemas kini textarea serta preview.\n5. **Responsive styling dan verification** -- Gaya senarai, dialog, thumbnail dan kawalan supaya kemas pada desktop/mobile, kemudian jalankan build, tests, diff check dan semak preview workflow.\n\n## Relevant files\n- `js/app.js:424-821`\n- `css/style.css:923-1038`\n- `server.js:16-74`\n- `src/data-store.js:56-65`\n- `index.html:66-92`\n
